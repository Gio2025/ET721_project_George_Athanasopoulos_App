# ET721_project_George_Athanasopoulos

-- Final Project


This final project will be a full-stack student learning application. The purpose of this application is to increase productivity and learning in students.

-- File Purposes:
# app.py 
This is the main file that routes between the different html files and paths, establishes the database connection, and checks for user validation. 

# init_db.py
Init_db is the file that is run in order to create the database "student_app.db". When it runs, it creates the tables(if they don't exist already) named "users" ,"tasks", "blogs", and "notes".
